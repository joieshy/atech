Windows 10 / 11

Mini PC setup

Para sa pisonet server, pisowifi billing at shop PC. Ito ang pinakamabilis at pinaka-karaniwang setup.

  • 4 GB RAM o higit pa
  • 64 GB storage
  • Windows 10/11 64-bit
  • LAN cable
  1. I-download ang installer Pumunta sa Installers, piliin ang tamang version at i-download ang ZIP file.
  2. I-extract sa sariling folder Right-click ang ZIP → Extract All → gawing C:\ATECH. Huwag patakbuhin ang setup sa loob mismo ng ZIP.
  3. Run as administrator Buksan ang setup.exe gamit ang right-click → Run as administrator para walang permission error.
  4. Sundan ang wizard Piliin ang install folder at port (default 8080). I-tick ang “create desktop shortcut” para madaling buksan.
  5. Allow sa firewall Kapag may Windows Firewall prompt, i-check ang Private networks at i-click ang Allow access.
  6. I-set ang admin password Buksan ang http://localhost:8080 sa browser at gumawa ng malakas na admin password.
  7. Static IP sa mini PC Control Panel → Network → IPv4 properties → hal. 192.168.1.10. Kailangan ito para hindi magbago ang IP ng server.
  8. I-test ang isang client I-install ang client sa isang unit, i-point sa server IP, at subukan ang coin slot o voucher bago i-rollout sa lahat.
Tip: I-off ang sleep/hibernate ng mini PC at i-exclude ang C:\ATECH sa antivirus kung na-block ang installer.

Armbian / Debian

Orange Pi setup

Para sa 24/7 na server — mababa ang konsumo sa kuryente, perfect para sa pisonet na laging bukas.

  • Orange Pi 3 / 5 / Zero 2
  • 16 GB+ microSD (A2)
  • Armbian o Debian image
  • Ethernet cable
  1. I-flash ang OS sa microSD Gamitin ang balenaEtcher para i-flash ang Armbian/Debian image sa microSD, tapos i-insert sa board.
  2. Unang boot at login I-connect ang LAN at monitor, pagkatapos mag-login gamit ang root / 1234. Mag-set agad ng bagong password at user.
  3. I-update ang system sudo apt update && sudo apt upgrade -y at i-install ang kailangan: sudo apt install -y unzip wget.
  4. I-upload ang installer Galing sa PC: scp installer.zip orangepi@192.168.1.20:/home/orangepi/. Palitan ang IP ng IP ng Orange Pi mo.
  5. I-extract at i-install sudo unzip installer.zip -d /opt/pisonet && cd /opt/pisonet tapos sudo chmod +x install.sh && sudo ./install.sh.
  6. I-enable ang service sudo systemctl enable --now pisonet at i-check kung tumatakbo: systemctl status pisonet.
  7. Buksan sa browser I-type ang http://192.168.1.20:8080 sa PC na kaparehas ng network. Gumawa ng admin password.
  8. I-fix ang IP sa router Mag-DHCP reservation sa router para laging 192.168.1.20 ang Orange Pi kahit mag-reboot.
Tip: Gumamit ng A2/Class 10 microSD o USB SSD para hindi mabilis masira ang card. I-monitor ang temperature gamit ang sensors o vcgencmd measure_temp.

APK / PisoTab

Android setup

Para sa tablet o phone na gagamitin bilang PisoTab, voucher station o remote monitor.

  • Android 8 o mas bago
  • 2 GB RAM
  • Parehong WiFi/LAN sa server
  1. I-download ang APK Buksan ang site sa phone/tablet at i-download ang APK file mula sa Installers.
  2. Payagan ang install from unknown apps Settings → Apps → Special access → Install unknown apps → piliin ang browser o file manager → Allow.
  3. I-install at buksan I-tap ang na-download na APK → Install → Open. Payagan ang storage at network permission.
  4. Ilagay ang server IP Sa app settings, ilagay ang IP ng mini PC o Orange Pi (hal. 192.168.1.10) at i-save.
  5. I-lock bilang kiosk Gamitin ang screen pinning o kiosk mode para hindi makaalis ang customer sa app.
  6. I-off ang auto-update I-disable ang Play Store auto-update para hindi mabago ang version habang ginagamit sa shop.
Tip: Kung “App not installed” ang error, i-check kung may dating version na naka-install. I-uninstall muna bago mag-install ng bago.

Network

Router at network setup

Isang beses lang ayusin — para stable ang IP ng server at hindi mawalan ng connection ang clients.

  • MikroTik / TP-Link / Tenda
  • Access sa admin panel
  • Listahan ng IP
  1. I-set ang LAN IP ng router Hal. 192.168.1.1 at DHCP range na 192.168.1.100–200 para may space sa mga fixed IP.
  2. DHCP reservation sa server I-bind ang MAC address ng mini PC / Orange Pi sa 192.168.1.10 (o .20) para hindi magbago.
  3. I-point ang captive portal Kung may portal, i-set ang DNS o portal URL papunta sa IP ng server para doon pumasok ang customers.
  4. I-test ang client I-connect ang isang device at siguraduhing nakakakuha ito ng IP, nakaka-open ng portal at may internet pagkatapos magbayad.
  5. I-record ang lahat Isulat ang router IP, server IP at admin password sa notebook o notes para hindi makalimutan.
Tip: Huwag i-port forward ang admin panel sa internet. Kung kailangan ng remote access, gumamit ng VPN.
