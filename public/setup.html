Setup guide

Kanya-kanyang setup guide,
para sa bawat device.

Tatlong device ang suportado — Mini PC (x86_64, ISO installer), Orange Pi One (prebuilt image) at NodeMCU coin box (ESP8266 firmware). Nasa Installers section ang mga files.

Piliin ang device Mini PCISO → USB → install Orange Pi OneImage → microSD → boot NodeMCUCoin box · ESP8266
x86_64 · Debian 13

Mini PC setup

Bootable ISO na may awtomatikong Debian install at Pay-Fi na naka-install sa dulo. I-boot lang at hintayin — walang manual partitioning.

  • x86_64 (Intel/AMD)
  • 4 GB RAM+
  • 16 GB+ disk
  • USB 4 GB+
  • LAN + internet
⚠️ Buburahin ang unang disk ng mini PC — partisyon at lahat ng laman. Huwag i-boot ang USB sa makinang may importanteng data. Kung 2+ ang disk, tatanungin ka ng installer kung alin ang gagamitin.

Part 1 — Pag-flash sa USB

  1. I-download ang ISO Kunin ang payfi-debian-minipc-amd64.iso sa Installers. Kung may .sha256 file, pwede mong i-verify bago i-flash.
  2. Ihanda ang USB flash drive 4 GB pataas. Mabubura din ang laman ng USB, kaya gumamit ng walang importanteng file.
  3. I-flash gamit ang Balena Etcher Flash from file → piliin ang .iso → Select target → ang USB → Flash! Hintayin ang “Flash Complete”.
  4. O kaya Rufus (Windows) Piliin ang ISO → Start → kapag nagtanong, piliin ang DD mode (hindi ISO mode) para tama ang hybrid boot.
Kailangan ng internet sa install. Netinst ang Debian base, kaya i-connect ang LAN cable na may internet (DHCP) bago i-boot.

Part 2 — I-boot at mag-install

  1. I-boot mula sa USB Isaksak ang USB sa mini PC at pindutin ang boot menu key — F12, F2 o Del depende sa board.
  2. Piliin ang automatic install Nasa Debian boot menu ang “Pay-Fi automatic install (ERASES the first disk)” — default na ito, hintayin ang 30s o pindutin ang Enter.
  3. Hintayin ang ~15–30 minuto Awtomatik: language, disk, users, packages, GRUB, tapos ang Pay-Fi install sa dulo. Depende sa bilis ng internet at disk.
  4. Tanggalin ang USB Awtomatikong mag-reboot. Tanggalin ang USB kapag nagsimula nang mag-boot mula sa internal disk.
  5. Hanapin ang IP at buksan ang dashboard Tingnan ang DHCP list ng router, tapos buksan ang http://<ip>:3000/admin sa browser.
Default credentials — palitan agad. Dashboard: admin / admin2234. Debian console/SSH: root / payfi2025 (at user payfi / payfi2025). Pagkatapos mag-login, palitan agad sa dashboard → Security, at sa Debian gamit ang passwd.

Part 3 — Setup sa dashboard

  1. Network → Routing I-assign ang roles: WAN = enp*/eth* na papunta sa modem, LAN/AP = pangalawang interface kung meron. I-on ang Auto WAN DHCP → Apply router setup.
  2. PayMongo Ilagay ang public at secret key para gumana ang online payment.
  3. Pricing at Vouchers I-set ang rates at gumawa ng voucher codes para sa customers.
  4. Security → Captive portal I-on ang captive portal → Apply rules. Ito ang magre-redirect sa customers papunta sa payment page.
  5. Fixed IP + bypass Para sa coin box o printer na hindi dapat hingan ng bayad: Network → Devices → Fixed/static IP → Fix + bypass.
Updates: System tab → Software update → Check for updates → Update now. Hindi nabubura ang data.db, settings at admin password.
I-download ang ISO Balik sa taas payfi-debian-minipc-amd64.iso
Orange Pi One · H3

Orange Pi setup

Prebuilt na image — flash lang sa microSD, boot, at bukas na ang dashboard. Walang SSH o manual install na kailangan.

  • Orange Pi One (H3)
  • microSD 8 GB+ (Class 10)
  • 5V 2A PSU (barrel)
  • LAN cable
  • USB WiFi dongle*
⚠️ Hardware check: isang Ethernet port lang at walang onboard WiFi ang Orange Pi One. Para makapag-serve ng customers, kailangan ng USB WiFi dongle na AP-capable (RTL8188EU / RTL8192CU / MT7601U / RT5370) o USB Ethernet adapter. Kung wala, dashboard lang ang gagana.

Part 1 — Pag-flash sa microSD

  1. I-download ang image Kunin ang payfi-orangepione-trixie-minimal.img.xz sa Installers. Huwag nang i-extract — direktang tinatanggap ng Etcher ang .img.xz.
  2. Ihanda ang microSD 8 GB pataas, Class 10 / A1. Mabubura ang laman, kaya i-backup muna kung may files.
  3. I-flash gamit ang Balena Etcher Flash from file → piliin ang .img.xz → Select target → ang microSD → Flash! Mga 5–10 minuto.
  4. I-cancel ang format prompt Kapag nag-“You need to format the disk” ang Windows pagkatapos mag-flash, i-click ang Cancel — normal lang iyon.
  5. Ilagay sa board Safe eject ang card, ilagay sa Orange Pi One, ikabit ang LAN cable, at saksakan ng 5V 2A sa barrel jack (huwag sa micro-USB/OTG).

Part 2 — First boot at dashboard

  1. Hintayin ang unang boot Mga 1–2 minuto. Awtomatikong nire-resize ang filesystem at may isang reboot.
  2. Hanapin ang IP Tingnan ang DHCP client list ng router. Sa console naman, ip -4 addr show.
  3. Buksan ang dashboard Dashboard: http://<ip>:3000/admin · Customer portal: http://<ip>:3000/
Default credentials — palitan agad. Dashboard: admin / admin2234. Armbian console/SSH: root / payfi2025. Nasa /opt/pay-fi/admin-initial-password.txt din ang dashboard password kung nakalimutan.

Part 3 — Setup sa dashboard

  1. Network → Routing WAN = eth0, AP = wlan0 kung may USB WiFi (o LAN = eth1 kung USB Ethernet). I-on ang Auto WAN DHCP → Apply router setup.
  2. WiFi AP (kung may dongle) WiFi tab → ilagay ang SSID at password → Start Access Point.
  3. PayMongo, Pricing at Vouchers I-set ang payment keys, rates at voucher codes.
  4. Security → Captive portal I-on at Apply rules para doon pumasok ang customers bago mag-internet.
  5. Coin slot sa GPIO (optional) NodeMCU → Coin Slot → Connection mode = SBC GPIO (Orange Pi One) → piliin ang pulse pin/edge → Save. 3.3V lang ang GPIO — gumamit ng optocoupler kung 12V ang acceptor.
Updates: System tab → Software update → Update now, o sa CLI: sudo bash /opt/pay-fi/scripts/update.sh. Hindi nabubura ang data.db at config.
I-download ang image Balik sa taas payfi-orangepione-trixie-minimal.img.xz
ESP8266 · Arduino IDE

NodeMCU coin box setup

Firmware ng coin acceptor — WiFi version. Ang board mismo ang nag-uulat ng barya sa server at sumusunod sa INHIBIT (bara) nito.

  • NodeMCU v2/v3 (ESP-12E)
  • USB data cable
  • CH340 / CP2102 driver
  • Arduino IDE
  • 12V coin acceptor
  • PC817 optocoupler
⚠️ 12V ang pulse ng coin acceptor, 3.3V lang ang GPIO ng ESP8266. Huwag ikabit nang diretso — gumamit ng optocoupler (PC817), 1kΩ sa LED side at 10kΩ pull-up papuntang 3.3V. Kailangan din ng common GND ng 12V supply at ng NodeMCU.

Part 1 — Ihanda ang Arduino IDE

  1. I-install ang Arduino IDE at driver I-download ang Arduino IDE 2.x at i-install. Kung hindi lumalabas ang port ng board, i-install ang CH340 o CP2102 driver para sa USB bridge nito.
  2. Idagdag ang ESP8266 board URL File → Preferences → Additional Boards Manager URLs at ilagay: https://arduino.esp8266.com/stable/package_esp8266com_index.json
  3. I-install ang ESP8266 core Tools → Board → Boards Manager → hanapin ang esp8266 (ESP8266 Community) → Install.
  4. Piliin ang board at port Tools → Board → NodeMCU 1.0 (ESP-12E Module), Upload Speed 115200, tapos piliin ang COM port ng board.

Part 2 — I-flash ang firmware

  1. Buksan ang firmware Ang file ay nodemcu/coinbox-wifi/coinbox-wifi.ino sa Pay-Fi repo. Ito ang WiFi version — hindi na kailangan ng USB serial sa server.
  2. Palitan ang DEVICE_ID kada board coinbox-1, coinbox-2, coinbox-3, … Kung pareho ang ID ng dalawang board, mag-o-overwrite ang counter nila sa isa't isa.
  3. I-upload Pindutin ang Upload (→) at hintayin ang “Done uploading”. Kung naka-stuck sa “Connecting…”, pindutin at hawakan ang FLASH button ng board habang nag-u-upload.
  4. Buksan ang Serial Monitor Baud: 115200. Itakda ang line ending sa Newline o Both NL & CR.
  5. I-check ang boot log Dapat may BOOT coinbox-wifi 1.0, MAC AA:BB:…, IP MODE dhcp, tapos STATUS … kada 5 segundo.
Custom board (eAzy MT & WS5 v2.0): may built-in optocoupler na, kaya huwag nang mag-PC817 — ikabit lang ang acceptor sa COINSLOT (+ = 12V, WHITE = pulse, − = GND). Default: coin sa D4 (GPIO2), inhibit sa D3 (GPIO0). Walang routing ang D2 sa board na ito.

Part 3 — WiFi setup ng board

  1. I-connect ang phone sa setup WiFi WiFi: CoinBox-Setup · password: coinbox123
  2. Buksan ang setup page http://192.168.4.1 kung hindi kusang bumukas ang dashboard.
  3. Ilagay ang settings AP SSID at password ng box, pati server host/port/token → I-save at kumonekta. Naka-save ito sa EEPROM ng board.
  4. I-check ang status Dapat CONNECTED at HTTP 200 para may heartbeat. Makikita rin dito ang IP (DHCP) at ang MAC ng board.
Case-sensitive ang SSID at kasama ang flag emoji sa dulo (hal. ShaiderBAM PisoWIFI). Kung “SSID HINDI MAKITA”, i-type ang SCAN sa Serial Monitor para makita kung anong SSID ang talagang nakikita ng board.

Part 4 — Pairing sa dashboard

  1. Itugma ang Connection mode Admin → NodeMCU → Coin Slot → piliin ang WiFi / network HTTP. Dapat tugma sa na-flash na firmware — kung hindi, tahimik na walang mabibilang.
  2. I-test ang coin slot Maghulog ng barya. Dapat tumaas ang counter at may POST /api/hardware/coins na nagre-return ng 200.
  3. (Optional) Fixed IP Admin → Network → Fixed / static IP devices → ilagay ang IP + MAC ng board. Laging DHCP ang firmware, kaya sa server gagawin ang reservation.
Diagnostics sa Serial Monitor: MON (hanapin kung D4 o D6 ang gumagalaw kapag may barya), SETPIN D3|D8, POLARITY NORMAL|INVERTED, SWEEP, at CLEAR (bura ng EEPROM).
